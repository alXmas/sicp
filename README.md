# SICP - Structure and Interpretation of Computer Programs

Этот репозиторий содержит материалы и решения заданий по курсу "Structure and Interpretation of Computer Programs" (SICP).

## О курсе

SICP - это фундаментальный курс по компьютерным наукам, разработанный в MIT. Курс представляет собой введение в вычислительные модели и принципы программирования. Он охватывает такие темы как:

- Абстракция и декомпозиция программ
- Процедурная и данностно-ориентированная абстракция
- Рекурсия и итерация
- Функции высшего порядка
- Символьные вычисления
- Мета-лингвистическая абстракция
- Объектно-ориентированное программирование
- Недетерминированные вычисления
- Логическое программирование

## Язык программирования

Курс использует язык Scheme (диалект Lisp) для иллюстрации концепций. Для выполнения заданий необходимо:

- Интерпретатор Scheme (рекомендуется MIT/GNU Scheme, Racket с пакетом sicp или Chez Scheme)
- Базовое понимание функционального программирования

## Структура репозитория

В репозитории будут храниться:
- Решения упражнений из книги
- Тесты для каждого упражнения
- Все файлы будут организованы по главам и разделам курса
